# Test Inputs — Q10 Self-Improving Prompt

## TI-1: A question with a genuine, fixable gap in a naive first answer

```
What's the time complexity of searching for an element in a Python list vs. a
Python dictionary?
```

## TI-2: A question where a good first answer likely has no real weakness (tests "No material weakness found" / critique theater)

```
What is 15% of 200?
```

## TI-3: A question prone to overconfident, unhedged answers if not critiqued (tests whether the critique catches missing caveats)

```
Is it safe to mix bleach and vinegar for cleaning?
```
